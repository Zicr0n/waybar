<img src="https://github.com/Zicr0n/waybar/blob/main/image.png">

## How to use
- Add all files to ~/.config/waybar. <br>
- Make sure you have wlogout for the power menu, otherwise remove the on-click in powermenu (config.jsonc). <br>
- For the center Arch button I've used wofi, you can probably change it to something else in the config.jsonc file (custom/appLauncher) <br>
- For the colors, you could make a symbolic link to your pywal waybar-colors. Or just manually choose colors.
